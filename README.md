# Vultur — club de arte marțiale, Chișinău

Landing page двуязычного сайта спортивного клуба. Румынский и английский,
переключение языка без перезагрузки страницы.

**Демо:** _сюда вставить ссылку после деплоя на Netlify_

## Что сделано

- Адаптивная вёрстка: десктоп, планшет, телефон
- Двуязычность RO/EN через `data-`атрибуты, без перезагрузки
- Фильтр расписания по дисциплинам, с сообщением о пустом результате
- Автоматическая подсветка текущего дня недели
- Таблица расписания, которая на мобильном превращается в карточки
- Форма записи с отправкой на почту (Formspree)
- Мобильное меню-бургер с корректными ARIA-атрибутами
- Поддержка `prefers-reduced-motion`, видимый фокус для клавиатуры
- Семантическая разметка, метатеги для поиска

## Стек

HTML5, CSS3 (Flexbox, CSS Grid), JavaScript. Без фреймворков и сборщиков.

## Структура

```
├── index.html
├── css/style.css
├── js/main.js
└── README.md
```

## Как запустить

Открыть `index.html` в браузере. Ничего устанавливать не нужно.

## Что настроить под себя

1. В форме заменить `YOUR_FORM_ID` на свой ID с [formspree.io](https://formspree.io)
2. В блоке `.map` вставить iframe с картой Google
3. Заменить заглушки `foto 3:4` в блоке тренеров на реальные фотографии
